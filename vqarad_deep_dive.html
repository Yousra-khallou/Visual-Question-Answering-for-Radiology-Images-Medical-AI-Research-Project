Format du dataset (fichiers)
Données Q&A
trainset.json / testset.json
Chaque entrée : image_name, question, answer, question_type (CLOSED/OPEN), answer_type. Format JSON, facile à charger avec pandas.
Images
Dossier /images
Images JPEG de tailles variables. Typiquement redimensionnées à 224×224 pour ResNet/ViT. Pas de split val officiel — tu dois le créer toi-même.
Pourquoi choisir VQA-RAD pour la recherche académique
Avantages
+ Benchmark standard — tous les papiers publient dessus
+ Taille gérable sur GPU moyen
+ Split test officiel pour comparaison directe
+ Questions annotées par type → ablations faciles
+ Scores SOTA publiés → facile de se situer
Limites à mentionner dans le papier
! Petit dataset (risque overfitting)
! Pas de split val officiel
! Déséquilibre de classes (beaucoup de "Yes/No")
! Annoté par des non-radiologues
! Biais de distribution question/réponse
